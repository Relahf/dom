# 🏢 Apartment Hub — Локальный хаб для многоквартирного дома

Полностью автономное веб-приложение для локальной сети многоквартирного дома с 8+ подъездами и сотнями пользователей. Работает на старом ПК под Linux без доступа в интернет.

## 🎯 Функциональность

| Модуль | Описание |
|--------|----------|
| 🔐 **Аутентификация** | Регистрация с логином, паролем, номером квартиры. Роли: администратор, житель |
| 💬 **Общий чат** | WebSocket чат с историей, эмодзи, звуковыми уведомлениями |
| 📁 **Файлообменник** | Загрузка/скачивание файлов, филь��рация, ограничения по размеру и месту |
| 📚 **Вики** | Создание статей с Markdown, полнотекстовый поиск, история версий |
| 🤖 **Локальная ИИ** | Ollama + Tinyllama с дневными лимитами запросов |
| ✉️ **Личная почта** | Сообщения между жильцами, индикатор прочтения |
| 📋 **Жалобы/предложения** | Анонимная система с отслеживанием статуса |
| 📢 **Доска объявлений** | Объявления с категориями, фото, комментариями |
| 🗳️ **Опросы** | Администраторы создают опросы с результатами в реальном времени |
| 📊 **Мониторинг** | CPU, RAM, диск, температура, статус ИБП (UPS) |
| ⚙️ **Админпанель** | Управление пользователями, модерация, резервные копии, настройки |
| 🌐 **Captive Portal** | Автоматический перенаправление всех HTTP-запросов на главную |

## 🚀 Быстрый старт

### Требования
- **Docker** и **Docker Compose**
- **Linux** (Ubuntu/Debian/CentOS)
- **4+ ГБ ОЗУ** (для Ollama)

### Установка

#### 1️⃣ Клонируйте репозиторий
```bash
git clone https://github.com/Relahf/dom.git
cd dom
```

#### 2️⃣ Создайте `.env` файл
```bash
cp .env.example .env
# Отредактируйте параметры при необходимости (опционально)
```

#### 3️⃣ Запустите приложение
```bash
docker-compose up -d
```

#### 4️⃣ Загрузите модель Ollama
```bash
docker exec -it ollama ollama pull tinyllama
```
⏳ Первый запуск займёт 5-10 минут (загрузка модели ~1.5 ГБ).

#### 5️⃣ Откройте приложение
```
http://localhost
```

**Первый зарегистрированный пользователь автоматически станет администратором.**

### Конфигурация DNS для реальной Wi-Fi сети

#### Вариант 1: На роутере (рекомендуется)
1. Войдите в админ-панель роутера (обычно 192.168.1.1)
2. Найдите настройки DHCP → DNS
3. Установите Primary DNS на IP вашего Linux-сервера (например, 192.168.1.100)
4. Все устройства в сети автоматически получат этот DNS

#### Вариант 2: Прямое подключение (тестирование)
```bash
# На Linux сервере проверьте IP
hostname -I

# Укажите в настройках Wi-Fi на клиентском устройстве IP этого сервера как DNS
```

#### Проверка работы
```bash
nslookup example.com <IP-СЕРВЕРА>
# Должен резолвиться в IP приложения
```

## 🐳 Docker Compose сервисы

### 1. `app` — FastAPI приложение
- Слушает на `0.0.0.0:80`
- SQLite БД в томе `/app/data`
- Загруженные файлы в томе `/uploads`

### 2. `ollama` — Локальная нейросеть
- Слушает на `0.0.0.0:11434`
- Модели хранятся в томе `/ollama/models`

### 3. `dnsmasq` — DNS + Captive Portal
- Слушает на `0.0.0.0:53` (UDP)
- Все DNS-запросы резолвятся в IP приложения
- Любой HTTP-запрос редиректится на `/` через HTTP 302

## 🔐 Безопасность

- ✅ **JWT токены** в HttpOnly cookies
- ✅ **Bcrypt хеширование** паролей
- ✅ **CSRF защита** на все формы
- ✅ **SQL injection защита** (SQLAlchemy ORM)
- ✅ **Rate limiting** на LLM запросы
- ✅ **Модерация чата** (администраторы)
- ✅ **Валидация входных данных** (Pydantic)

## 🐛 Решение проблем

### Ollama не загружает модель
```bash
docker exec -it ollama ollama pull tinyllama
# Если медленно, используйте более лёгкую модель:
docker exec -it ollama ollama pull orca-mini
```

### WebSocket не работает
- Проверьте: `docker ps` (должны быть 3 контейнера)
- Проверьте логи: `docker-compose logs app`
- Убедитесь, что порт 80 не занят

### DNS не перехватывается
```bash
# Проверьте резолверы
nslookup example.com 127.0.0.1
nslookup example.com <IP-СЕРВЕРА>

# Перезагрузите dnsmasq
docker-compose restart dnsmasq
```

### Диск переполнен
```bash
# Удалите старые файлы через админку или напрямую
rm -rf /path/to/uploads/*

# Или создайте резервную копию и очистите
```

### БД потеряла целостность
```bash
# Используйте резервную копию
cd /backups
tar -xzf apartment_hub_backup_*.tar.gz
```

## 📝 Первые шаги

### 1. Создайте администратора
- Откройте `http://localhost`

### 2. Отредактируйте профиль
- Укажите номер квартиры
- Загрузите аватар

### 3. Откройте админпанель (`/admin`)
- Просмотрите статистику
- Создайте дополнительных админов
- Настройте лимиты LLM
- Включите автоматические резервные копии

### 4. Пригласите жильцов
- Поделитесь URL приложения
- Научите менять DNS на Wi-Fi роутере

## 🌐 Первое подключение жильца

1. Подключиться к Wi-Fi дома
2. Открыть любой браузер и перейти на любой сайт (например, google.com)
3. Автоматически перенаправится на главную страницу приложения
4. Зарегистрироваться или войти

## 💡 Советы и рекомендации

- **Минимум порты:** Приложение работает только на порту 80 (HTTP)
- **Без интернета:** Все сервисы работают локально, интернет не требуется
- **Масштабируемость:** Кэширование, индексирование и WAL режим БД обеспечивают производительность
- **Монитор:** Регулярно проверяйте использование диска и оперативной памяти
- **Резервные копии:** Регулярно создавайте резервные копии

## 🤝 Поддержка и вопросы

Если возникли проблемы:
1. Проверьте логи: `docker-compose logs app`
2. Убедитесь, что все контейнеры запущены: `docker ps`
3. Перезагрузитесь: `docker-compose restart`
4. Переустановитесь: `docker-compose down && docker-compose up -d`
